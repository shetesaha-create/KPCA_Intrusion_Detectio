# ML-Algorithms-Project

Repository containing 75 code snippets supplied in five source files, organized into five folders of 15 programs each.

## Structure

- `01_SVM_Kernel_Programs/` — Programs 1–15
- `02_SVM_Train_Test_Split/` — Programs 16–30
- `03_SVM_Preprocessing/` — Programs 31–45
- `04_SVM_Kernel_PCA/` — Programs 46–60
- `05_SVM_Kernel_Experiments/` — Programs 61–75
- `source_notes/` — Original uploaded Markdown files retained as supplied

## Important

The `.py` files contain the code blocks exactly as they appeared in the uploaded Markdown. No code cleanup, formatting, bug fixes, or logic changes were applied. Some source code blocks appear to have lost line breaks before upload, so the `.py` files may need restoration from the original source if executable formatting is required.

## Dataset

The code references CIC-IDS-style CSV files such as `Tuesday-WorkingHours.pcap_ISCX.csv`, `Wednesday-workingHours.pcap_ISCX.csv`, and `Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv`. These datasets are not included; place the required CSV files where the scripts expect them before running.
